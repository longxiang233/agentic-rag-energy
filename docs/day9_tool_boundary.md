## 1.三个工具分别解决什么问题

| 工具 | 解决什么问题 | 不解决什么问题 |
| ---- | ---- | ---- |
| policy_search | 政策条款、补贴标准、并网规则、容量补偿 | 电价数字、通用概念 |
| price_query | 峰谷电价、容量补偿单价、现货价格 | 政策条款原文、通用概念 |
| vector_search | 通用概念、行业背景、术语解释 | 精准电价数字、结构化政策条款 |

## 3.docstring三要素
| 工具 | 功能 | 参数 | 返回 | 什么场景用 | 不适用场景 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| policy_search | 帮助用户查询政策条款 | query | 返回政策原文 | 涉及到政策条款、补贴标准、并网规则、容量补偿时 | 当问到电价数字、通用概念的时候 |
| price_query | 帮助用户查询电价 | query | 返回精准的电价数字 | 查询峰谷电价、容量补偿单价、现货价格 | 不适合政策条款原文、通用概念 |
| vector_search | 帮助用户解决通用问题 | query | 概念，术语 | 查询行业术语，通用概念 | 查询政策和电价 |

"""查询新能源政策条款、补贴标准、并网规则、容量补偿机制。

返回：政策原文片段+来源文件。
不适用：查具体电价数字用 price_query，查通用概念用 vector_search。"""

"""查询山东峰谷电价、容量补偿单价、现货价格上限下限。

返回：结构化电价数字+来源。
不适用：查政策条款原文用 policy_search，查通用概念用 vector_search。"""
